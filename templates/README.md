# 模板资产

本目录两类资产：SVG 图表模板（模式 A）+ 报告解读模板（模式 B）。

## 一、SVG 图表模板（模式 A · 二创型）

每个 `.html` 是一个 SVG 设计源，用 Chrome headless 渲染成 png 入 `images/`：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars \
  --screenshot="images/XX-名称.png" --window-size=1200,780 \
  "file://$(pwd)/XX-名称.html"
```

（封面用 `--window-size=2350,1000` 凑 2.35:1）

### 配色（Anthropic）
底 `#F0EEE6` / 字 `#2A2825` / 强调橙 `#DA7756` / 次要灰 `#7A776F` / 块底 `#E6E2D6` / 表格线 `#D5D0C4`

### 模板说明
| 文件 | 尺寸 | 结构 | 改什么 |
|---|---|---|---|
| `封面-示例.html` | 2350×1000 | 左单节点 → 箭头+10x → 右网络节点 | 主/副标题、节点文字（"我的AI"→"我们的AI"那类对照） |
| `概念图-三层嵌套示例.html` | 1200×780 | 三层同心圆 + 右侧逐行说明 | 圈层标签、说明文字、底部旁注 |
| `金句卡-示例.html` | 1200×780 | 纯文字排版 | 金句文字 |

用法：复制一份，搜原文替换文字即可，SVG 结构（圆/线/坐标）直接复用。

## 二、报告解读模板（模式 B · 报告解读型）

### `报告导读模板包.md`
导读/镜像写作的 5 个 RG 模板（源自 chapter-content-generator skill 的 T1-T19 精选改编），每个含：骨架 + 真实示例 + 检查清单。

| 编号 | 名称 | 放在哪 | 干什么 |
|---|---|---|---|
| RG-1 | 经验激活 | 导读开头 | 2-3 个真实数据画面建立体感 |
| RG-2 | 概念对比卡 | 概念首次出现处 | 一张表看清易混概念差异 |
| RG-3 | 方法流程图 | 方法介绍段 | 报告方法链 ```text 可视化 |
| RG-4 | 易混淆警告框 | 数据密集处 | `> ⚠️ **注意这个误读**` 防误读 |

另有组合建议（导读/镜像/总序各用哪几个）+ 轻量版质量清单（9 项）。

### `Seedream配图任务书-示例.md`
生图工具（以 Seedream 为例，换用其他工具时格式照用）生成视觉隐喻图的任务书范例（Anthropic Economic Index 二部曲实战版），含：
- 统一视觉规范（Anthropic 暖色 + 抽象极简人文风格 + 共同约束）
- 每张图的表格（编号/标题/放置位置/尺寸/隐喻）+ 英文 Prompt + 风格备注
- 核心策略：**Seedream 图只放导读和镜像（我们自己的部分），不和原报告图撞车**——原图=数据，Seedream=解读

用法：复制一份，按新报告的章节主题改隐喻方向和 Prompt，5 张图（2 封面 + 3 概念图）为典型配置。
