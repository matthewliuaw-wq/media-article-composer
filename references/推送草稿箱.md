# 推送公众号草稿箱（Playwright 网页操作）

> 版本 v0.1（2026-10-12）。依据一次真实推送整理；公众号后台改版后部分选择器可能需要调整，遇到新问题请补进文末踩坑清单和案例记录。
> 只用于自己有管理或运营权限的公众号，低频手动触发，不要做成批量自动发文。
> 适用：文章已经排成公众号样式的 HTML（全部内联样式），要放进公众号后台草稿箱，由用户本人预览后发表。

## 为什么用网页操作而不用接口

接口方式（draft/add）需要 AppID、AppSecret、服务器 IP 白名单，个人订阅号常常没有素材管理和草稿箱接口权限。网页操作只需要用户扫码登录，效果等同于人工复制粘贴，样式所见即所得。代价是依赖后台页面结构，微信改版后选择器可能要调整，所以每一步都截图确认，不要一口气跑完。

经常发文、账号又有接口权限时，可以另做接口版脚本；本文件只管网页操作。

## 安全边界（先读）

- **登录由用户扫码完成。** 不输入、不索要密码或 AppSecret。
- **保存草稿前停下来**，把标题、作者、封面、正文的截图给用户看，得到明确同意再点“保存为草稿”。注意：编辑器会**自动保存**，正文粘贴进去不久草稿就已经出现在草稿箱里，要如实告诉用户。
- **不点“发表”“群发”**，也不改“原创声明”“合集”“赞赏”等设置，除非用户明确要求。
- 结束后关闭 Playwright 标签页（不要点“退出登录”），删除 `.playwright-mcp/` 下的截图和日志——里面有账号后台画面。
- 文中涉及第三方机构名称、学员作品、学员原话等待授权内容，推送前提醒用户；进草稿箱不等于公开，但要说清楚。

## 准备

| 项目 | 说明 |
|---|---|
| 排版 HTML | 内联样式；本地图片用相对路径（如 `配图/01_xxx.gif`）；列表项内容已包在 `<p>` 里（`swap_wechat_urls.py` 也会补） |
| 配图 | GIF ≤10MB（建议 ≤5MB）；PNG/JPG 均可 |
| 封面 | 单独做一张 2.35:1（如 900×383 JPG），后台还会从同一张图裁 1:1 分享卡片，主体尽量居中 |
| 标题、作者、摘要 | 标题 ≤64 字；摘要 ≤120 字 |
| 本地静态服务 | Playwright MCP 禁止 `file://`，用 `.claude/launch.json` 起一个 `python3 -m http.server`（目录指向文章文件夹）供读取正文 HTML |
| Playwright MCP | 截图只能存到工作目录下（如 `.playwright-mcp/xxx.png`），存 `/tmp` 会被拒 |

## 流程

每一步用 `browser_run_code_unsafe` 跑一段代码，跑完截图看一眼再进下一步。下面的代码是 2026-10 案例里实际跑通的写法。

### 1. 打开后台，用户扫码

`browser_navigate` 到 `https://mp.weixin.qq.com/`，截图给用户，请对方扫码并在手机上选账号。等跳转：

```js
async (page) => {
  await page.waitForURL(/cgi-bin\/home|token=/, { timeout: 90000 }).catch(() => {});
  return page.url().replace(/token=\d+/, 'token=***');   // 回报时遮掉 token
}
```

登录后截一次首页，**确认账号名**，告诉用户是哪个号。

### 2. 批量上传配图和封面到素材库

素材库图片页有 `input[type=file]`（multiple，支持 gif），直接塞文件，不必逐张点：

```js
async (page) => {
  await page.getByText('素材库', { exact: true }).first().click();
  await page.waitForTimeout(3000);
  const dir = '/Users/你的用户名/文章文件夹/配图/';   // 配图文件夹的绝对路径；Windows 写成 'C:/Users/你的用户名/文章文件夹/配图/'
  const files = ['00_封面.jpg', '01_xxx.gif' /* … */].map(f => dir + f);
  await page.locator('input[type=file]').first().setInputFiles(files);
  for (let i = 0; i < 60; i++) {           // 等上传结束
    await page.waitForTimeout(2000);
    if (!(await page.locator('text=/上传中|正在上传|%/').count()) && i > 3) break;
  }
}
```

截图核对：图片总数增加了对应张数，缩略图都在。

### 3. 读出每张图的微信图链

缩略图以 `background-image` 形式挂在文件名附近的容器上，按文件名找回去：

```js
async (page) => {
  const names = ['00_封面.jpg', '01_xxx.gif' /* … */];
  return await page.evaluate((names) => {
    const out = {};
    const leaves = [...document.querySelectorAll('*')].filter(e => e.children.length === 0);
    for (const n of names) {
      const label = leaves.find(e => e.textContent.trim() === n || e.textContent.trim().startsWith(n.slice(0, 8)));
      let card = label;
      for (let i = 0; i < 6 && card; i++) {
        card = card.parentElement;
        const img = card && card.querySelector('img');
        const bg = card && [...card.querySelectorAll('*')].map(x => getComputedStyle(x).backgroundImage).find(b => b.includes('mmbiz'));
        if (img || bg) { out[n] = (img ? img.src : bg.match(/url\("(.+?)"\)/)[1]).replace(/&amp;/g, '&'); break; }
      }
    }
    return out;
  }, names);
}
```

把结果存成 `图链.json`（文件名 → 图链），然后：

```bash
python3 <本 skill 目录>/scripts/swap_wechat_urls.py 排版.html 图链.json 正文_微信图链.html
```

脚本会报告图片张数、修正的列表项数和正文字数；有图没找到图链会列出来并退出。

### 4. 新建文章，填标题、作者、摘要

首页“新的创作 → 文章”会**打开新标签页**，后续操作都在这个页里：

```js
async (page) => {
  const ctx = page.context();
  await page.getByText('首页', { exact: true }).first().click();
  await page.waitForTimeout(2500);
  const np = ctx.waitForEvent('page', { timeout: 15000 });
  await page.locator('text=/^文章$/').first().click();
  const ed = await np;
  await ed.waitForTimeout(5000);
  const pms = ed.locator('.ProseMirror');            // 第 0 个是标题，第 1 个是正文
  await pms.nth(0).click();
  await ed.keyboard.insertText('标题');
  await ed.locator('#author').pressSequentially('作者', { delay: 20 });
  await ed.locator('#js_description').fill('摘要');
}
```

之后的代码用 `page.context().pages().find(p => p.url().includes('appmsg_edit'))` 找到编辑器页。

### 5. 粘贴正文

经剪贴板以 `text/html` 粘贴，等同人工复制粘贴，内联样式能保留：

```js
async (page) => {
  const ctx = page.context();
  const ed = ctx.pages().find(p => p.url().includes('appmsg_edit'));
  await ctx.grantPermissions(['clipboard-read', 'clipboard-write'], { origin: 'https://mp.weixin.qq.com' });
  const html = await (await ctx.request.get('http://localhost:<端口>/' + encodeURIComponent('正文_微信图链.html'))).text();
  await ed.evaluate(async (h) => {
    await navigator.clipboard.write([new ClipboardItem({
      'text/html': new Blob([h], { type: 'text/html' }),
      'text/plain': new Blob([h.replace(/<[^>]+>/g, '')], { type: 'text/plain' }) })]);
  }, html);
  // 用脚本聚焦正文，不要点击：顶部工具栏会挡住点击
  await ed.evaluate(() => { const pm = document.querySelectorAll('.ProseMirror')[1]; pm.focus();
    const r = document.createRange(); r.selectNodeContents(pm); getSelection().removeAllRanges(); getSelection().addRange(r); });
  const mod = process.platform === 'darwin' ? 'Meta' : 'Control';   // macOS 用 Command，Windows/Linux 用 Ctrl
  await ed.keyboard.press(`${mod}+A`);    // 重新粘贴时先清空
  await ed.keyboard.press('Backspace');
  await ed.keyboard.press(`${mod}+V`);
  await ed.waitForTimeout(8000);
}
```

核对：正文图片数（编辑器里每张图旁会多一个 `ProseMirror-separator`，按 `img.rich_pages` 计数）、“正文字数”、列表项是否同行。图片可能懒加载，滚动到位后再看 `naturalWidth`。

### 6. 设封面

“拖拽或选择封面” → “从图片库选择” → 点中封面缩略图 → “下一步” → 核对 2.35:1 与 1:1 两个裁切 → “**确认**”。

- 选图时**点缩略图本身**（文件名上方约 50px 处的坐标），按祖先容器去点会点错到别的图。
- 编辑封面的按钮叫“确认”，不叫“完成”；对话框较高时按钮在可视区外，先把视口调高（如 1290×1500）。

### 7. 停下来确认，再保存

截取正文开头、一个结构较密的中段、文末三张图给用户，同时说明自动保存的情况。用户同意后点“保存为草稿”，看到绿色“已保存”提示、左侧“历史版本”出现“手动保存”记录即成功。

### 8. 核对草稿箱，收尾

直接打开草稿箱列表（侧栏菜单可能折叠点不到）：

```js
async (page) => {
  const token = (page.url().match(/token=(\d+)/) || [])[1];
  await page.goto(`https://mp.weixin.qq.com/cgi-bin/appmsg?begin=0&count=10&type=77&action=list_card&token=${token}&lang=zh_CN`);
}
```

确认第一张卡片的封面、标题、更新时间无误。然后关闭全部标签页、删除 `.playwright-mcp/`，提醒用户：手机预览动图与版式、自行设置原创和合集、自己点发表。

## 踩坑清单

| 现象 | 原因与做法 |
|---|---|
| 打开本地 HTML 报 `file:` 被拦 | Playwright MCP 禁止 `file://`，起本地 http 服务 |
| 读本地 HTML 跨域失败 | 在后台页面里 `fetch` localhost 会被 CORS 拦，改用 `page.context().request.get()`（在 Playwright 进程里取，不受 CORS 限制） |
| 截图保存失败 | 只能存在工作目录下 |
| `#title` 点不到 | 那是隐藏的 textarea；可见的标题是第一个 `.ProseMirror` |
| 列表里加粗词和后文被拆成两行 | 编辑器要求 li 内是块级内容；li 内容整体包进 `<p>`（脚本自动处理） |
| 点正文报“元素被遮挡” | 顶部工具栏盖住了点击位置；用 `focus()` 加 selection 代替点击 |
| 摘要计数器一直显示 0/120 | 文本框里有内容、保存后仍在；最终在草稿里打开核对一次 |
| 封面选错图 | 按缩略图坐标点选，见第 6 步 |
| 粘贴后很快出现在草稿箱 | 编辑器自动保存，属正常，要告诉用户 |
| 弹出“未授权使用切换账号能力” | 与本流程无关，忽略 |
